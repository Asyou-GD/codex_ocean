# Ocean Shallows v1.1.1

[English](v1.1.1-en.md)

重做海豚点击后的跃水动作。上一版使用俯视姿态贴图抬升，缺少身体破水的过程；这一版用 48 帧三维姿态呈现抬头出水、尾部离水、空中弓背转体和头先入水。水线将身体分成清晰的水上部分与带青绿色透射的水下部分，入水后短暂潜没再恢复游动。

出水时喷出扇形水雾，入水时产生更集中的喷柱、泡沫和扩散涟漪。海豚沿原泳向继续前进，落水后平滑回到队形。消息框和原生控件的点击优先级保持不变。

## 下载与更新

- `Ocean-Shallows-v1.1.1-macOS.zip`
- `Ocean-Shallows-v1.1.1-Windows.zip`
- `SHA256SUMS.txt`

备份当前引擎中的 JavaScript 和 CSS，将包内 `assets/renderer-inject.js` 与目标平台的 `dream-skin.css` 放进同一个实际运行的引擎 `assets` 目录。Windows 使用包内 `assets/windows/dream-skin.css`，目标名称为 `dream-skin.css`。重新应用 **Ocean Shallows Live**。

首次安装时，先安装对应平台的 Dream Skin 1.5.21，引擎和 App 本次不更新。通过软件的「打开主题文件夹」定位主题库，复制整个 `themes/preset-ocean-shallows` 并选择已保存主题。[目录说明](https://github.com/Asyou-GD/codex_ocean/tree/v1.1.1#找到软件实际使用的文件夹) · [Windows 步骤](https://github.com/Asyou-GD/codex_ocean/blob/v1.1.1/docs/windows.md)
