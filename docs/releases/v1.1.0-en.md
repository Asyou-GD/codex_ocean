# Ocean Shallows v1.1.0

[中文](v1.1.0.md)

Click a pink dolphin to make it leap. Its body rises along an arc while its shadow stays on the water; landing produces droplets, expanding foam rings and GPU ripples. Clicking open water produces a smaller splash. Dry sand does not generate ripples.

Codex keeps priority inside messages, the composer, sidebar, header, links, buttons and popovers. A dolphin underneath a message does not respond. Dragging, text selection, scrolling and keyboard input retain native behavior. Clicking an airborne dolphin does not restart its jump. Changing themes removes the sea's pointer listeners.

macOS and Windows use the same renderer. Platform styles retain transparent messages and the anchored sidebar preview fix. These resources work with Dream Skin 1.5.21 and do not replace the stock App.

## Download and update

- `Ocean-Shallows-v1.1.0-macOS.zip`
- `Ocean-Shallows-v1.1.0-Windows.zip`
- `SHA256SUMS.txt`

Extract the package for your platform. Back up the current engine JavaScript and CSS, then copy `assets/renderer-inject.js` and the matching platform stylesheet into the same active engine `assets` folder. On Windows, use `assets/windows/dream-skin.css` and name the destination file `dream-skin.css`. Reapply **Ocean Shallows Live** in Dream Skin.

For a first installation, install Dream Skin 1.5.21 for your platform first. Use the software's “Open themes folder” menu to locate the actual theme library, copy the whole `themes/preset-ocean-shallows` directory into it, install both renderer files, then choose the saved theme. [Folders and menus](https://github.com/Asyou-GD/codex_ocean/tree/v1.1.0#找到软件实际使用的文件夹) · [Windows guide](https://github.com/Asyou-GD/codex_ocean/blob/v1.1.0/docs/windows.md)

## Validation

Both platform payloads were tested in independent Chrome fixtures covering dolphin leaps and landings, water taps, protected chat controls, dragging and selection, zoom coordinates, listener cleanup, native-structure anchored previews, animated water, Retina, suspension and GPU context recovery. Shared resource generation and both platform payload checks passed.

Dolphin clicks in the native Codex window and installation/display on a Windows desktop still require verification on the target computer.
