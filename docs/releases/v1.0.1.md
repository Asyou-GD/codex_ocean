# Ocean Shallows v1.0.1

修复侧栏聊天条目的悬浮详情卡片错误出现在窗口左上角的问题。卡片使用原生锚点跟随对应条目定位，毛玻璃效果应用在可见的卡片表面。

本次更新同步提供 macOS 和 Windows 的配套资源，兼容 Dream Skin 1.5.21。粉色海豚群与动态水面的功能沿用 v1.0.0。

## 下载与更新

- `Ocean-Shallows-v1.0.1-macOS.zip`
- `Ocean-Shallows-v1.0.1-Windows.zip`
- `SHA256SUMS.txt`

解压对应平台的资源包，备份当前引擎中的 JavaScript 和 CSS，然后将包内配套的 `renderer-inject.js` 与目标平台的 `dream-skin.css` 放到当前引擎的同一个 `assets` 目录，重新应用 **Ocean Shallows Live**。Windows 使用包内 `assets/windows/dream-skin.css`，复制到引擎后文件名为 `dream-skin.css`。

首次安装时，先安装对应平台的 Dream Skin 1.5.21 引擎，再同步两份资源。从软件菜单「打开主题文件夹」，放入包内的整个 `themes/preset-ocean-shallows` 目录，在「已保存主题」中选择它。[目录与菜单说明](https://github.com/Asyou-GD/codex_ocean/tree/v1.0.1#找到软件实际使用的文件夹) · [Windows 步骤](https://github.com/Asyou-GD/codex_ocean/blob/v1.0.1/docs/windows.md)

## 验证范围

两套平台资源均通过使用原生浮层结构的浏览器定位检查，以及海景动画、输入、Retina、GPU 恢复和主题切换检查。普通对话框的渲染检查通过。

原生 Codex 窗口的悬停交互仍需实机复核。
