# Ocean Shallows v1.1.2

[English](v1.1.2-en.md)

修复海豚入水瞬间看似消失、随后重新出现的断层。原先水下部分固定为 12% 透明度，身体跨过水线时会骤暗；现在保留粉色、体积明暗和青绿水色，透明度随水深连续变化，完全入水后仍能看到身体轮廓。

完整动作延长到约 2.8 秒，保留起跳和空中段的速度，为水下续游与恢复姿态留出时间。最后约 0.65 秒平滑接回正常游姿，同时对齐身体位置。点击保护与出入水涟漪规则不变。
