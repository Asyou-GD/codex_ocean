# Ocean Shallows v1.1.0

[English](v1.1.0-en.md)

粉色海豚现在可以点击起跳。身体沿弧线抬升，阴影留在水面，落水时产生飞溅水滴、扩散泡沫圈和 GPU 涟漪。点击空白海面也会泛起小波纹，沙滩不产生水纹。

消息框、输入框、侧栏、标题栏、链接、按钮和浮层内的点击仍由 Codex 处理。海豚游到消息框下面时不会响应点击。拖动、选字、滚动与键盘操作保留原生行为；重复点击正在起跳的海豚不会重新开始动作。切换主题会移除海景指针监听。

macOS 与 Windows 共用本次渲染代码，配套样式继续保留透明消息框和侧栏悬浮详情定位修复。兼容 Dream Skin 1.5.21，本次资源包不更换原版 App。

## 下载与更新

- `Ocean-Shallows-v1.1.0-macOS.zip`
- `Ocean-Shallows-v1.1.0-Windows.zip`
- `SHA256SUMS.txt`

解压对应平台资源包，备份当前引擎的 JavaScript 和 CSS，再将包内的 `assets/renderer-inject.js` 与对应平台的 `dream-skin.css` 放进当前引擎的同一个 `assets` 文件夹。Windows 使用包内 `assets/windows/dream-skin.css`，复制后名称为 `dream-skin.css`。在软件中重新应用 **Ocean Shallows Live**。

首次安装时，先安装对应平台的 Dream Skin 1.5.21 引擎，再同步两份资源。从软件菜单「打开主题文件夹」，放入整个 `themes/preset-ocean-shallows` 目录，并在「已保存主题」中选择它。[菜单与目录说明](https://github.com/Asyou-GD/codex_ocean/tree/v1.1.0#找到软件实际使用的文件夹) · [Windows 步骤](https://github.com/Asyou-GD/codex_ocean/blob/v1.1.0/docs/windows.md)

## 验证范围

两套平台资源经过独立 Chrome 场景验证，覆盖海豚起跳与落水、点水涟漪、聊天控件保护、拖动和选字、缩放坐标、监听清理、原生结构悬浮卡片定位，以及海景动画、Retina、设备挂起和 GPU 丢失恢复。共享资源生成和双端 payload 检查通过。

原生 Codex 窗口中的点击效果，以及 Windows 桌面安装与显示，仍需目标电脑实机确认。
