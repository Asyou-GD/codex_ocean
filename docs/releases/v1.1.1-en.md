# Ocean Shallows v1.1.1

[中文](v1.1.1.md)

Rebuilt the dolphin breach animation. The previous version lifted an overhead sprite without showing the body crossing the surface. A new 48-frame 3D sequence now shows the nose rising, the tail leaving the water, an arched turn in the air and a head-first re-entry. The waterline separates the clear airborne body from the translucent teal underwater portion. The dolphin briefly submerges before resuming its swim.

Takeoff produces a fan of spray; landing produces a concentrated jet, foam and spreading ripples. The dolphin continues along its swimming direction and smoothly rejoins the pod after landing. Messages and native controls retain click priority.

## Download and update

- `Ocean-Shallows-v1.1.1-macOS.zip`
- `Ocean-Shallows-v1.1.1-Windows.zip`
- `SHA256SUMS.txt`

Back up the active engine JavaScript and CSS. Copy `assets/renderer-inject.js` and the matching platform `dream-skin.css` into that engine's `assets` folder. On Windows, use `assets/windows/dream-skin.css` and name the destination file `dream-skin.css`. Reapply **Ocean Shallows Live**.

For a first installation, install Dream Skin 1.5.21 for your platform. This release does not replace the App or engine launcher. Locate the actual theme library through the software's “Open themes folder” menu, copy the whole `themes/preset-ocean-shallows` directory and choose the saved theme. [Folder guide](https://github.com/Asyou-GD/codex_ocean/tree/v1.1.1#找到软件实际使用的文件夹) · [Windows guide](https://github.com/Asyou-GD/codex_ocean/blob/v1.1.1/docs/windows.md)

## Validation

Both platform payloads passed shared generation and payload checks, plus independent Chrome regressions covering breach frames, takeoff and entry events, repeated clicks, protected chat controls, dragging and selection, zoom, Retina, GPU recovery and theme switching. The 3D atlas was visually reviewed frame by frame.

Native Codex click rendering and installation on a Windows desktop still require confirmation on the target computer.
